install & run

three steps and you're driving

  1. download the installer

    ShitboxRally_Setup.exe from the latest release. if you'd rather not use an installer, grab ShitboxRally-win64.zip, unzip it anywhere and run the exe.

  2. run it

    windows may show a SmartScreen warning because the game isn't signed. click More info, then Run anyway.

  3. drive

    the game checks for updates when it starts, so you only install once. really old installs (0.5 and earlier) can't update themselves, just run the installer again.

system requirements

a rough guide, not a promise.

os
windows 10 or 11, 64-bit
gpu
anything with Vulkan or OpenGL 3.3
disk
about 1 GB
controls
keyboard works, a gamepad is better, a wheel with force feedback is best

running on a potato

  • older and integrated GPUs fall back to OpenGL and pick a lighter preset on their own.
  • graphics presets go from Potato to Native in settings. they only change what's drawn, never the physics.
  • the Potato preset runs on integrated graphics.
  • longer stages take longer to build on slow machines, so start short.

stable or dev

stable is the latest release and only updates to the next stable one. dev builds are pre-releases with the newest stuff, and they'll probably break a bit. the channel is baked into the build you install.

found a bug?

use Settings → Stats & feedback in the game. it goes straight to the dev.
